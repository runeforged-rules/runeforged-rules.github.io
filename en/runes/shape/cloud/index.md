# **Cloud**

Spreads the effect in an area by generating a cloud that persists over time, hitting creatures within it.

| **Primary Targets**   | None                                   |
| **Secondary Targets** | All creatures within the area   |
| **Base Cost per LV**  | 700 mana                                  |
| **Defense Mod.**        | CON / ARC                                 |

## Effect
Generates a static cloud that applies the substance's effects in a specified area. Every time a creature ends their turn within the area, they are hit as a secondary target. The cloud remains static and does not move with wind or other external factors.
