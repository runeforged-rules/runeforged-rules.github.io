# **Hollow Projectile**

This rune does not replace the evocation's shape but preserves it.
Launches a projectile that hits the first object it finds. If it hits a target or exceeds maximum range, the evocation assumes the preserved shape.

| **Primary Targets**   | None                                   |
| **Secondary Targets** | First object hit in a straight line  |
| **Base Cost per LV**  | 50 mana                                   |
| **Defense Mod.**        | DEX                                       |

## Effect
The projectile travels in a straight line and hits the first object it finds. After impact or upon reaching maximum range, the evocation assumes the preserved shape, originating from the point and in the direction of the impact.
