# **Projectile**

Launches a projectile that hits the first object it encounters along its path.

| **Primary Targets**   | First object hit                     |
| **Secondary Targets** | None                                   |
| **Base Cost per LV**  | 100 mana                                  |
| **Defense Mod.**        | DEX                                       |

## Effect
Travels in a straight line and hits the first object it finds. If it exceeds maximum range without hitting anything, it dissipates into the air without producing further effects.

| Grade 0 | Grade 1 | Grade 2 | Grade 3 | Grade 4 | Grade 5 |
|---------|---------|---------|---------|---------|---------|
| Range 10m | Range 20m | Range 30m | Range 40m | Range 50m | Range 60m |
