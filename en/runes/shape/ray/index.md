# **Ray**

Launches a ray that continues in a straight line, hitting every creature it crosses along the path.

| **Primary Targets**   | Creatures within the trajectory    |
| **Secondary Targets** | None                                   |
| **Base Cost per LV**  | 500 mana                                  |
| **Defense Mod.**        | None                                   |

## Effect
Propagates instantly from the point of origin, hitting all creatures within the ray's range. The ray passes through creatures but dissipates if it encounters significant solid obstacles.
