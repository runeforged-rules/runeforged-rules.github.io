# **Seal**

This rune does not replace the evocation's shape but preserves it.
Preserves the evocation in a fixed place, activatable via physical contact or another evocation.

| **Primary Targets**   | None                                   |
| **Secondary Targets** | None                                   |
| **Base Cost per LV**  | 100 mana                                  |
| **Defense Mod.**        | None                                   |

## Effect
Immediately places a seal, which can be positioned on a solid surface or even suspended in the air. The seal preserves the evocation at the specified position. When activated (via physical contact or when targeted by an evocation), the seal releases the preserved shape, allowing its effect to be executed.
