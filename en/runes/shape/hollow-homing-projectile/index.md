# **Hollow Homing Projectile**

This rune does not replace the evocation's shape but preserves it.
Marks a target and then launches a projectile that chases it. If it hits it or exceeds maximum range, the evocation assumes the preserved shape.

| **Primary Targets**   | None                                       |
| **Secondary Targets** | Target hit                             |
| **Base Cost per LV**  | 200 mana                                      |
| **Defense Mod.**        | None                                       |

## Effect
Marks a specific target. The launched projectile chases it, dodging obstacles in the path. If it hits the target or exceeds range, the evocation assumes the preserved shape.
