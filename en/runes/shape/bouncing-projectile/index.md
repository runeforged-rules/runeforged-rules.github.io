# **Bouncing Projectile**

Launches a projectile that bounces after hitting the first object, continuing to travel and hitting a second target.

| **Primary Targets**   | Second target hit after bouncing  |
| **Secondary Targets** | First target hit                     |
| **Base Cost per LV**  | 150 mana                                  |
| **Defense Mod.**        | DEX                                       |

## Effect
Travels in a straight line and hits the first object it encounters. After impact, it bounces and continues its path in a new straight-line direction. If it exceeds maximum range without hitting a second target, it dissipates into the air without further effects.
