# **Hollow Instant Projectile**

This rune does not replace the evocation's shape but preserves it.
Launches a projectile that teleports to the chosen target, immediately assuming the preserved shape.

| **Primary Targets**   | None                                   |
| **Secondary Targets** | Chosen target                          |
| **Base Cost per LV**  | 600 mana                                  |
| **Defense Mod.**        | None                                   |

## Effect
The rune allows you to select a target within range. The projectile teleports to its position and immediately transforms into the preserved shape. The projectile cannot be blocked, dodged, or cancelled in any way.
