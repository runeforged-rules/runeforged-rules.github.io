# **Instant Projectile**

Launches a projectile that teleports to the target instantly, guaranteeing the hit.

| **Primary Targets**   | Chosen target                          |
| **Secondary Targets** | None                                   |
| **Base Cost per LV**  | 500 mana                                  |
| **Defense Mod.**        | None                                   |

## Effect
The rune allows you to select a target within range. By teleporting the projectile directly to its position, it hits immediately without possibility of error. This attack ignores any obstacle between the point of origin and the target, and the hit cannot be blocked in any way.
